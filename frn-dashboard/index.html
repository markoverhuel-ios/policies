FRN Dashboard

FCC license tracking dashboard for iOS

OverviewPrivacySupport

FRN Dashboard tracks FCC wireless licenses by FRN (FCC Registration Number). Add an FRN, and the app pulls in every license on file for it directly from the FCC's public ULS system, then organizes it by status, expiration, and location.
